# ジグザグ撮影 正方形の撮影画面とカメラロール選択 spec（2026-11-03 v1）

## 目的

倉庫の玉城さんの相談（#倉庫関連 C043DMY8HL7、thread_ts 1793061794.240529）に応える。

1. 1:1 を選んだとき、撮影中の画面も正方形にする。どこまで写真に残るかを撮る前に分かるようにする。
2. 撮影のほかに、端末のカメラロールから写真を選んで登録できるようにする。

今は端末のカメラアプリを開いて撮るため、撮影中に枠を出せない。撮った後に中央を正方形に切り抜いている。

## 入口と画面の流れ

- 入口は今までと同じ `shoot.html?w=<作業者ID>`（`zigzag_shoot_20261026_v1.html` へ移る）。
- ラベルを読んだあとの「写真を撮る」（下の主ボタン）と「写真を追加」を押すと、ページの中のカメラが全画面で開く。
  - 1:1 のとき、映るのは正方形の枠の中だけにする。4:3 のとき、カメラの画面全体を映す。
  - 画面の上に 4:3 と 1:1 の切り替えを置く。切り替えると枠もすぐ変わる。
  - 下の「撮る」ボタンで撮る。2枚目まで撮るか、「写真を追加」から1枚撮ったら、カメラを閉じて登録の画面に戻る。
  - 見出しは「正面を撮ってください」「裏かタグを撮ってください」「追加の写真を撮ってください」を枚数で替える。
- 写真の欄に「写真を選ぶ」を置く。押すと capture を付けない入力が開き、カメラロールの写真を選べる。複数枚まで選べ、残りの枚数（8枚まで）を超えた分は入れない。iPhone ではこの入力から撮影も選べる。
- ページの中のカメラを起動できない端末（許可しなかった、未対応）では、今までどおり端末のカメラアプリを開く。

## 写真の扱い

- 撮った写真は動画の1コマ全体を JPEG にし、今の `addPhoto` に渡す。1:1 の切り抜き、元の写真（orig）の保持、形を替えたときの切り抜き直しは今の処理のまま使う。
- 1:1 の枠は、1コマの中央の正方形と同じ範囲を映す。`cropRect` と同じ範囲になる。
- カメラは横 1920 × 縦 1440 を目安に頼む。登録時は今までどおり長い辺を 1600px にする。
- 画面を離れたら（別のアプリに切り替えたら）カメラを止める。戻ったときにカメラの画面が開いていれば、もう一度起動する。
- ラベル読み取りのカメラとは同時に開かない。

## 完了条件

1. `node --test tests/` が通る。
2. ローカルのプレビューで、入口から「写真を撮る」を押してカメラの画面が開き、1:1 で正方形の枠になる。撮った写真が登録画面に正方形で並ぶ。
3. 「写真を選ぶ」から画像を選ぶと、登録画面に並ぶ。
4. 本番（GitHub Pages）で同じ流れを入口から確かめる。倉庫のスマホでの写り（ピント、明るさ）は玉城さんに試してもらう。
